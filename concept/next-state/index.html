次の状態

試したあと、どうなった？ 予想と違う日も大切。

CCTとは？

CCTは、日々の調子を暮らし・体と心・行動のつながりから考えるための見方です。

「その後の調子」を詳しく見るページです。次の条件に戻っていくところまで考えます。 CCTの図を見る →

  1. その前の暮らし
  2. 今のサイン
  3. とった行動
  4. その後の調子

これって何？

次の状態は、その日や翌日に起きた変化のこと。眠気、食欲、気分、次の行動のしやすさなど、最初に気になっていたものを見直します。

ここで初めて「変えてみたこと」と「起きたこと」を比べます。良い変化があればうれしい。でも、変化がなかった日も、仮説を見直す材料になります。

たとえば、こんな日

週末の予定を一つ減らして休んだなら、その後の気分や眠り、翌週の過ごしやすさを見ます。細かな点数をつける必要はありません。

変化がなかったとしても、自分を責める必要はありません。気分の落ち込みが続くなら、別の工夫を探し続けるより、相談することも大切です。

見るなら、ここから

  • 試そうとしたことを実行できたか
  • 最初に決めた体感や行動はどう変わったか
  • 同時に変わった予定や体調はなかったか

決めつけないために

「気分が沈む日が続いている」は観察。「予定が原因だ」は仮説です。少数の記録で原因や効果は証明できません。
