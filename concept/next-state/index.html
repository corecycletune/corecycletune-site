Core Cycle Tune / つながりをたどる

次の状態

今日の調子は、明日の選択にも関わる。

CCTとは？

CCTは、気になる変化から複数のつながりをさかのぼり、繰り返す流れを整えていく考え方です。

行動の後の変化を見て終わらず、その状態が翌日の暮らしや行動にどう戻るかを考えます。循環の折り返しに当たる見方です。 つながりの図を見る →

  1. 今のサイン
  2. その前の暮らし
  3. とった行動
  4. その後の調子

これって何？

次の状態は、その日や翌日に起きた変化のこと。眠気、食欲、気分、次の行動のしやすさなど、最初に気になっていたものを見直します。

ここで初めて「変えてみたこと」と「起きたこと」を比べます。良い変化があればうれしい。でも、変化がなかった日も、仮説を見直す材料になります。

その後を分けると

一つの行動の直後だけではなく、翌日の暮らしまで見ると、循環が続いているかが分かりやすくなります。

その日の体感

眠気、空腹感、気分。変えたことの直後だけで判断しない。

夜の選択

疲れた日に何を食べたか、動画を見たか、休めたか。次の眠りにもつながる。

翌日の暮らし

朝の疲れ、食事の取り方、外へ出る機会。結果が次の条件になる。

たとえば、こんな日

寝不足の朝に疲れを感じ、夕方には外に出る気力がない。夜にまた動画で息抜きして遅く寝る。この流れが繰り返されるなら、翌朝の状態が次の夜の条件にもなっています。

夜に画面を閉じる時刻を変えてみたら、翌朝だけでなく、その日の活動や次の夜も見ます。変化がなければ別の線を考えます。

見るなら、ここから

  • 試そうとしたことを実行できたか
  • 最初に決めた体感や行動はどう変わったか
  • 同時に変わった予定や体調はなかったか

決めつけないために

「気分が沈む日が続いている」は観察。「予定が原因だ」は仮説です。少数の記録で原因や効果は証明できません。

次に読んでみる

また〈身体反応〉や〈感情・欲求〉から、次の日のサインを見直せます。別の条件が重なっていないかも確かめましょう。

CCTの6要素と用語はCCT Lab独自の整理です。モデル全体の効果や診断精度は検証されていません。研究と限界もあわせてご覧ください。
