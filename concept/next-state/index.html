試したあと、どうなった？ 予想と違う日も大切。

CCTとは？

CCTは、日々の調子を暮らし・体と心・行動のつながりから考えるための見方です。

「その後の調子」を詳しく見るページです。次の条件に戻っていくところまで考えます。 CCTの図を見る →

  1. その前の暮らし
  2. 今のサイン
  3. とった行動
  4. その後の調子

これって何？

次の状態は、その日や翌日に起きた変化のこと。眠気、食欲、気分、次の行動のしやすさなど、最初に気になっていたものを見直します。

ここで初めて「変えてみたこと」と「起きたこと」を比べます。良い変化があればうれしい。でも、変化がなかった日も、仮説を見直す材料になります。

たとえば、こんな日

午後に短い休憩を取る日を作ったなら、その後の集中や夕方の疲れを記録します。以前と同じ指標で比べると、印象だけで判断しにくくなります。

変化がなければ、作業内容や睡眠など別の条件が大きかったのかもしれません。一手で生活すべてが変わることを期待しなくて大丈夫です。

見るなら、ここから

  • 試そうとしたことを実行できたか
  • 最初に決めた体感や行動はどう変わったか
  • 同時に変わった予定や体調はなかったか

決めつけないために

「夕方も疲れていた」は観察。「休憩の取り方が悪かったから」は仮説です。体感には日ごとの揺れがあり、少数の記録で原因や効果は証明できません。
