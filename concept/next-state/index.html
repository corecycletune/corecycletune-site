CCTとは？

CCTは、気になる変化から複数のつながりをさかのぼり、繰り返す流れを整えていく考え方です。

行動の後の変化を見て終わらず、その状態が翌日の暮らしや行動にどう戻るかを考えます。循環の折り返しに当たる見方です。 つながりの図を見る →

  1. その前の暮らし
  2. 今のサイン
  3. とった行動
  4. その後の調子

これって何？

次の状態は、その日や翌日に起きた変化のこと。眠気、食欲、気分、次の行動のしやすさなど、最初に気になっていたものを見直します。

ここで初めて「変えてみたこと」と「起きたこと」を比べます。良い変化があればうれしい。でも、変化がなかった日も、仮説を見直す材料になります。

たとえば、こんな日

寝不足の朝に疲れを感じ、夕方には外に出る気力がない。夜にまた動画で息抜きして遅く寝る。この流れが繰り返されるなら、翌朝の状態が次の夜の条件にもなっています。

夜に画面を閉じる時刻を変えてみたら、翌朝だけでなく、その日の活動や次の夜も見ます。変化がなければ別の線を考えます。

見るなら、ここから

  • 試そうとしたことを実行できたか
  • 最初に決めた体感や行動はどう変わったか
  • 同時に変わった予定や体調はなかったか

決めつけないために

「気分が沈む日が続いている」は観察。「予定が原因だ」は仮説です。少数の記録で原因や効果は証明できません。

次に読んでみる

〈生活条件〉に戻って、次の日の予定や環境も見ます。循環の中でどこを変えやすいか考え直せます。
