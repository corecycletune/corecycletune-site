Core Cycle Tune

コアサイクルチューンとは

CCT（コアサイクルチューン）は、気分や体調の変化を手がかりに、日々の暮らしを振り返り、動かせるところを少しずつ調整するための考え方です。

「最近、気分が沈みがちだな」。そんなとき、睡眠、予定、人との関わり方に変化がなかったかを見る。負担を減らせそうなことを試し、その後の自分の様子を確かめます。

What is CCT?

気分の変化から、暮らしを振り返る

数日間、気分が重い。そんな変化に気づいたら、その前の暮らしや自分の行動を振り返ります。ひとつの出来事だけで理由を決めつけず、いくつかの可能性を考えます。

たとえば気分が沈む日が増えたなら、睡眠や予定、人との関わりに変化がなかったか振り返ります。ひとつの原因を探し当てるのではなく、負担を減らせそうなところを見つけるためです。

A Way to Read

身近な場面に当てはめると

気分の落ち込み、朝のだるさ、夜の過ごし方。気になる変化を手がかりに、その前後を見てみます。

最近の気分

気分が沈む日が増えた

予定が重なった週。休む時間や誰かと話す余裕はあった？　負担を減らせることがあるか考える。

朝の体調

朝から体が重い

前夜の睡眠や朝の予定はどうだった？　体の重さが続く日と、そうでない日を比べてみる。

夜の行動

寝る前に画面を見続ける

連絡が気になっていた？　休む時間は取れた？　翌朝の様子も含めて振り返る。

前後を並べても原因は一つに決まりません。確かめられたことと推測を分け、無理なく変えられるところを探します。

Six Lenses

詳しく見るための6つの要素

暮らし、サイン、行動、その後の調子を、もう少し細かく分けてみます。「今のサイン」は体と気持ちに、「とった行動」はその場の行動と日々の時間の使い方に分かれます。

01生活条件予定や環境など、その前にあった事情。詳しく見る → 02身体反応眠気、空腹、疲れなど体のサイン。詳しく見る → 03感情・欲求休みたい、落ち着きたいなどの気持ち。詳しく見る → 04行動その場で実際にしたこと。詳しく見る → 05生活リズム起きる・食べる・休む時刻の並び。詳しく見る → 06次の状態その後や翌朝に、どうなったか。詳しく見る →

6つの番号は整理の順番です。人体に実在する6つの回路や、必ず通る段階を指しません。

Two Useful Words

流れを読み解く2つの言葉

前後のつながりをたどり、「どこを少し変えてみよう」と考えるときに使うCCT独自の言葉です。

Dissonance

不協

気になる変化に関わっていそうな条件や行動の候補。たとえば、予定が続いて休む時間を取りにくかったこと。

人や性格への評価ではなく、見直す場所を見つけるための仮の名前です。

Resolution

解決

その候補に対して試す、小さく具体的な一手。たとえば予定を一つ減らし、その後の調子を見ること。

「必ず良くなる」という結論ではなく、試して振り返る行動です。

解決を詳しく読む →

分けて考える：「気分が沈む」は今のサイン。「予定が重なっていた」は条件。「予定を一つ減らす」は試す行動です。予定が原因だと決まったわけではありません。

Try It Gently

日常では、こう使う

詳しい記録よりも、まず一つの場面から。CCTは生活を考えるための手順で、治療プログラムではありません。

  1. 気になる場面を決める

    「ここ数日、気分が沈む」のように、気になった変化を一つ挙げる。

  2. 前後をたどる

    最近の睡眠や予定、休めた時間を振り返る。事実と推測を分ける。

  3. 一つだけ試す

    負担を減らせることを一つ試し、その後の様子を見る。

  4. 考え直してよい

    変化がなくても自分を責めない。調子がつらいときは人や専門家に相談する。

Evidence and Limits

分かっていること・まだ分からないこと

気分の落ち込みには、睡眠や行動の変化が伴うことがあります。ただし、暮らしを振り返るだけで、その原因や病気の有無は分かりません。

変化に気づく

厚生労働省の「こころの耳」は、いつもと違う睡眠、気分、行動などを、こころの不調に気づく手がかりとして挙げています。

こころの耳：いつもと違う様子に気づく

Medical Note

医療との関係

CCTは日常の過ごし方を振り返るための見方で、診断や治療の代わりにはなりません。気分の落ち込みが強い、長く続く、生活に支障が出ているときは、一人で生活を調整し続けず医療機関や相談窓口に相談してください。急な痛みや息苦しさなど、体の症状が強い場合も医療機関への相談を優先してください。厚生労働省の相談窓口案内も利用できます。
