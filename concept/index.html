Core Cycle Tune

コアサイクルチューンとは

コアサイクルチューン（循環調律）は、眠気や食欲など、日々の調子を「その日だけの問題」で終わらせず、前後の暮らしと一緒に見ていく考え方です。

たとえば夜に食べすぎたら、帰宅時間、空腹、疲れ、翌朝の調子まで見てみる。自分を責めるためではなく、次にできる小さな一手を見つけるためです。

Mechanism

6段階はどう「循環」するのか

今日の疲れや空腹は、今夜の過ごし方に関わるかもしれません。そして今夜の過ごし方は、明日の朝にも関わるかもしれません。その流れをたどるのがCCTです。

時間をまたぐ

夕方の眠気や空腹が夜の選択に関わり、夜の過ごし方が翌朝の調子に関わる。どのつながりも、その人に当てはまるか確認します。

複数の入口がある

眠い理由を食事だけで決められないように、予定や睡眠なども一緒に見ます。一つの体感から原因を言い当てることはできません。

次の条件を変える

変えられそうなことを一つ試し、どうなったかを見る。予想と違ったら、別の条件を考えます。

位置づけ：6段階と「コアサイクル」はCCT Lab独自の整理です。人体に実在する単一の回路や、臨床試験で有効性が確認された治療法を指しません。

Dissonance / Resolution

不協と解決

コアサイクルチューン（循環調律）では、生活の好循環を乱す行動や状態を不協、それを整える行動を解決として扱います。

Dissonance

不協

生活の循環を乱し、次の乱れにつながっていく要素です。

  • 疲れているのにスマホを見続ける
  • 強い空腹のまま夜の食事を迎える
  • 就寝時刻が遅くなり、睡眠の機会が減る
不協を詳しく見る →

Resolution

解決

乱れた流れを整え、次の行動を少し軽くするための行動です。

  • 夕方に軽食を入れて空腹を弱める
  • スマホを寝室に持ち込まない
  • 食後に少し歩いてリズムを切り替える
解決を詳しく見る →

不協、症状、解決の区別

不協は循環を乱し得る行動・条件・状態。眠気やだるさなどの症状・体感は現れた結果として別に記します。解決は原因と見立てた箇所に働きかける、試行可能な行動です。ある日の食べすぎはその日の結果であり、翌日の条件にもなり得ます。

「夕方に空腹が強い（観察）→食事間隔が関係するかもしれない（仮説）→帰宅前の食べ方を変える（試行）」と書き分けます。変化がなければ仮説を修正します。

Example

夜の過食をCCTで見る例

夜の食事が多くなる日を生活の流れとして見る、CCTの仮説例です。誰にでも同じ変化が起きると示したものではありません。

不協の流れ

  1. 生活条件：帰宅が遅い
  2. 身体反応：疲労と空腹が強い
  3. 感情・欲求：満たされたい感覚が強まる
  4. 行動：コンビニや外食で食べすぎる
  5. 生活リズム：就寝が遅れる
  6. 次の状態：翌朝だるく、また崩れやすくなる

解決の流れ

  1. 生活条件：夕方に軽食を入れる
  2. 身体反応：空腹がやわらぐか観察する
  3. 感情・欲求：焦りや衝動の変化を観察する
  4. 行動：帰宅後の食事量を確認する
  5. 生活リズム：就寝時刻に変化があるか確認する
  6. 次の状態：翌朝の状態を記録し、予想と比べる

Observe / Try / Review

日常で調律する4つの手順

難しい記録は要りません。「いつ、何が気になったか」から始められます。これは生活を考えるための手順で、治療プログラムではありません。

  1. 困りごとを具体化する「昼食後、14時ごろに眠い」のように、場面を一つ書く。
  2. 前後の条件を並べる前夜の睡眠や食事、仕事の予定を並べる。分かったことと推測は分ける。
  3. 変える点を一つ選ぶたとえば夕方の空腹が気になるなら、食事の間隔を変えられるか考える。
  4. 同じ指標で振り返る試せたか、夜や翌朝の状態はどうだったかを同じ方法で見る。

仮説が外れたら

試しても変わらなかったら、見立てを変えて構いません。仕事や睡眠など、別の事情が関係したかもしれません。日々の記録だけで原因を証明することはできません。

Evidence and Limits

研究でわかることと、CCTの未検証部分

生活の一部を調べた研究と、CCTというメソッド全体の有効性は別の問いです。

睡眠と摂取量の一例

短時間睡眠が習慣になっている過体重の成人を対象とした2週間の無作為化試験では、睡眠延長を支援した群のエネルギー摂取量が対照群より減りました。全員や長期間に当てはまるとは言えません。

Tasali ほか、2022：原著論文

反対の結果もある

別の睡眠制限実験では、食欲と摂取量がむしろ低下しました。「睡眠不足なら必ず過食する」と単純化できません。

Radcliffe ほか、2021：原著論文

CCT全体の効果は未検証

6段階、不協・解決の分類、4つの手順を一体として検証した試験は、現時点で提示できません。CCT自体の効果や診断精度を証明したものとして扱いません。

Medical Note

医療との関係

CCT Labは、医療機関での診断や治療の代わりになるものではありません。

病気の診断、治療方針、薬の開始・中止・増減、検査結果の判断は、医師や医療専門職の領域です。体調不良が強い場合、症状が長引く場合、急な痛みや息苦しさなどがある場合は、医療機関への相談を優先してください。

CCT Labが扱うのは、医療と日常のあいだにある生活実践です。睡眠を整える、食べ方を見直す、歩く、呼吸を整える、刺激を減らす、記録して振り返る。そうした日々の小さな行動を、生活の循環として考えます。
