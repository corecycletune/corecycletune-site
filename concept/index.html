Core Cycle Tune

コアサイクルチューンとは

CCT（コアサイクルチューン）は、日々の調子を、暮らし・体と心・行動のつながりから考えるための見方です。

たとえば、午後に集中できない日。眠気だけに注目せず、その前に何があったか、どう過ごしたか、その後どうなったかを一緒に見ます。

What is CCT?

CCTは、調子を「一日の流れ」で考える見方です

眠い、元気が出ない、集中できる。そんな身近な調子の変化から、その前と後にある暮らしをたどります。

たとえば「午後に眠い」なら、眠気の前の予定や休憩、そのときにしたこと、夕方の様子まで見てみます。原因を断定するためではなく、自分が変えられそうなところを探すための地図です。

A Way to Read

身近な場面に当てはめると

朝のだるさも、昼の集中も、夜の過ごし方も。気になる場面から前後の流れをたどれます。

朝

朝からだるい

前夜の就寝が遅かった。朝はだるくて、少しゆっくり支度した。午前中はどう感じたかも見てみる。

昼

集中が続かない

予定が続いた午後、眠気に気づく。席を立って一息ついた。その後の集中はどう変わっただろう。

夜

寝る前に画面を見続ける

連絡が気になって画面を見る。寝る時刻が後ろにずれた。翌朝の様子まで含めて振り返る。

前後を並べても原因は一つに決まりません。確かめられたことと推測を分け、無理なく変えられるところを探します。

Six Lenses

詳しく見るための6つの要素

暮らし、サイン、行動、その後の調子を、もう少し細かく分けてみます。「今のサイン」は体と気持ちに、「とった行動」はその場の行動と日々の時間の使い方に分かれます。

01生活条件予定や環境など、その前にあった事情。詳しく見る → 02身体反応眠気、空腹、疲れなど体のサイン。詳しく見る → 03感情・欲求休みたい、落ち着きたいなどの気持ち。詳しく見る → 04行動その場で実際にしたこと。詳しく見る → 05生活リズム起きる・食べる・休む時刻の並び。詳しく見る → 06次の状態その後や翌朝に、どうなったか。詳しく見る →

6つの番号は整理の順番です。人体に実在する6つの回路や、必ず通る段階を指しません。

Two Useful Words

流れを読み解く2つの言葉

前後のつながりをたどり、「どこを少し変えてみよう」と考えるときに使うCCT独自の言葉です。

Dissonance

不協

次の困りごとに関係していそうな条件や行動の候補。たとえば、休む時間が取れないまま夜を迎えること。

人や性格への評価ではなく、見直す場所を見つけるための仮の名前です。

不協を詳しく読む →

Resolution

解決

その候補に対して試す、小さく具体的な一手。たとえば休憩の時刻を少し変え、午後の状態を見ること。

「必ず良くなる」という結論ではなく、試して振り返る行動です。

解決を詳しく読む →

分けて考える：「午後に眠い」は体感。「休憩が少なかった」は条件。「休憩を取る時刻を変える」は試す行動です。眠気の原因をこの三つだけで決めることはできません。

Try It Gently

日常では、こう使う

詳しい記録よりも、まず一つの場面から。CCTは生活を考えるための手順で、治療プログラムではありません。

  1. 気になる場面を決める

    「午後の会議で眠い」のように、いつ・どこでを一つ書く。

  2. 前後をたどる

    睡眠、予定、休憩、体感、行動を並べる。観察したことと推測を分ける。

  3. 一つだけ試す

    変えられる範囲で小さく試し、予想した変化があったかを見る。

  4. 考え直してよい

    変化がなければ別の条件を考える。うまくいかない日を失敗と呼ばない。

Evidence and Limits

研究とCCTの境界

睡眠や食事など個別の研究はあります。ただし、それらはCCTという地図全体の効果を証明するものではありません。

研究で調べられたこと

短時間睡眠が習慣になっている過体重の成人の試験では、睡眠を延ばす支援を受けた群のエネルギー摂取量が対照群より減りました。

Tasali ほか、2022：原著論文

結果は一様ではない

別の睡眠制限実験では、食欲と摂取量が低下しました。睡眠と食欲の関係を、いつも同じ結果になると考えることはできません。

Radcliffe ほか、2021：原著論文

CCTについて言えること

6つの要素や不協・解決はCCT Lab独自の整理です。全体の効果や診断精度を確かめた試験は提示できません。

Medical Note

医療との関係

CCTは日常の過ごし方を振り返るための見方で、診断や治療の代わりにはなりません。病気や薬の判断は医療専門職に相談してください。症状が強い、長引く、急な痛みや息苦しさがある場合は医療機関への相談を優先してください。
