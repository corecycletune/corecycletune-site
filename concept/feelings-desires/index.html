Core Cycle Tune / つながりをたどる

感情・欲求

気分の変化は、一つの原因へ直結しない。いくつかの線をたどる。

CCTとは？

CCTは、気になる変化から複数のつながりをさかのぼり、繰り返す流れを整えていく考え方です。

気分や欲求を入口に、睡眠、予定、人との関わりなど複数の線を考えます。気持ちが次の行動を変えることもあります。 つながりの図を見る →

  1. その前の暮らし
  2. 今のサイン
  3. とった行動
  4. その後の調子

これって何？

気分が沈む、不安になる、休みたい、一人になりたい。そうした気持ちや欲求は、実際に何をしたかとは分けて考えます。

「人と会いたくない」と感じる日があっても、その理由をすぐに一つに絞ることはできません。予定の多さ、疲れ、心配事など、重なっているものがあるかもしれません。

たとえば、こんな日

気分が沈む日が増えた。寝不足、予定の重なり、人と話す機会の減少をそれぞれ確かめます。寝不足の背景に夜の動画があるなら、さらに動画を見続けた理由もたどれます。

気分が重くて外出を控えたなら、活動の減少は気分の前にも後にも現れます。どちらが先かは日によって違うかもしれません。

見るなら、ここから

  • 何をしたい、何を避けたいと感じたか
  • その前の疲れや緊張はどうだったか
  • 実際にはどんな選択肢があったか

決めつけないために

「気分が重い」は体感、「一人で休みたい」は欲求、「予定を断った」は行動です。きれいに分けられない日もあります。記録がつらければ無理に続けず、気分の落ち込みが続くときは人や専門家に相談してください。
