Core Cycle Tune / Key concept

不協

うまく回らない日、どこでつまずいた？

まず全体像を知りたい方へ

不協は図の決まった位置ではありません。どの場所にもあり得る、見直す条件・行動の候補です。 CCTの図を見る →

これって何？

不協は、次の困りごとにつながっていそうな条件や行動に、CCTがつけた名前です。人の性格や病気に貼るラベルではありません。

たとえば、仕事の連絡が夜まで続いて休む機会が少ない。その連絡の多さは、翌朝のだるさに関係するかもしれない条件として挙げられます。ただ、それが原因と決まったわけではありません。

たとえば、こんな日

朝にだるさを感じる日が続くなら、前夜の連絡、寝る機会、朝の予定を見ます。連絡が少ない日にもだるいのか。比べて初めて、見立ての手がかりになります。

仕事や家庭の事情で変えられない条件があるなら、そこを責めても役に立ちません。動かせる部分を探すための言葉です。

見るなら、ここから

  • 困りごとの前に、何が繰り返し起きていたか
  • 変えられる条件と変えにくい条件
  • 観察した事実と、自分の推測

決めつけないために

眠気やだるさは、まず症状・体感として書きます。「夜に休む機会が少なかった」は不協の候補になり得ますが、それだけで眠気の原因とは決めません。
