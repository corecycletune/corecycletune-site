Core Cycle Tune / Key concept

不協

気分が沈む日が増えた。暮らしのどこに負担があるだろう。

CCTとは？

CCTは、日々の調子を暮らし・体と心・行動のつながりから考えるための見方です。

不協は図の決まった位置ではありません。どの場所にもあり得る、見直す条件・行動の候補です。 CCTの図を見る →

これって何？

不協は、次の困りごとにつながっていそうな条件や行動に、CCTがつけた名前です。人の性格や病気に貼るラベルではありません。

たとえば予定が続き、休む時間が取りにくい。その予定の多さは、気分の変化に関わるかもしれない条件の一つです。ただし、それが原因と決まったわけではありません。

たとえば、こんな日

気分が沈む日が増えたなら、最近の予定、休めた時間、人との関わりを振り返ります。予定が少ない日も同じようにつらいなら、別の見方も必要かもしれません。

仕事や家庭の事情で変えられない条件があるなら、そこを責めても役に立ちません。動かせる部分を探すための言葉です。

見るなら、ここから

  • 困りごとの前に、何が繰り返し起きていたか
  • 変えられる条件と変えにくい条件
  • 観察した事実と、自分の推測

決めつけないために

気分の落ち込みは、まず自分が感じた変化です。「休む時間が少なかった」は不協の候補になり得ますが、それだけで原因とは決められません。つらさが続く場合は専門家にも相談してください。
