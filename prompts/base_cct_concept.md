# base_cct_concept.md

このファイルは CCT（Core Cycle Tune / コアサイクルチューン）の概念を定義する。
記事構成のテンプレートではない。

## CCTとは何か

CCTは、日常の困りごとを一つの原因へ還元せず、
**状態・条件・行動・結果が互いに次を呼び、繰り返す循環**として読むための枠組みである。

睡眠、食事、運動、呼吸、姿勢、光、刺激、感情、仕事、人間関係などは独立した健康項目ではない。
その日の条件の中でつながり、次の状態を作る。

CCTでは、

状態を観察する
→ 次の乱れを呼んでいるつながりを探す
→ 小さな介入を入れる
→ 次の状態・行動を見る
→ 仮説を更新する

という反復を Tune と考える。

## 不協（ディゾナンス / Dissonance）

不協は、単なる症状や「悪いもの」の分類ではない。

**ある状態・行動・条件が、次の乱れを呼び、その連鎖が自己強化していく関係・作用**を不協として読む。

例：

予定が詰まる
→ 頭が疲れる
→ 手軽な刺激・短期報酬を求める
→ ショート動画を開く
→ 次々スクロールする
→ 就寝が遅れる
→ 翌朝さらに疲れる
→ 予定に余裕がなくなる

この場合、動画だけが不協なのではない。
疲労から短期刺激へ流れること、視聴が就寝を後ろへ送ること、睡眠不足が翌日の余裕を削ることなど、
**次の乱れを呼ぶ接続**に注目する。

一つの行動は状況によって不協にも、そうでないものにもなる。

## 解決（レゾリューション / Resolution）

解決は「健康に良い行動」の別名ではない。

**不協の連鎖へ働きかけ、その次の状態・行動を変える介入候補**である。

例：

予定を少し減らす
→ 疲れ切る前に休める
→ 夜に残る余裕が増える
→ 動画を切り上げやすくなるか観察する
→ 睡眠機会が残る
→ 翌朝の余裕が増える
→ 次の日も休憩を組みやすくなる

解決は正解ではなく仮説である。
入れても次の状態が変わらなければ、別の介入点を探す。

## ディゾナンス・サイクル

不協が次の不協を呼び、最初の状態をさらに強める自己強化ループ。

## レゾリューション・サイクル

解決によって次の状態が変わり、
次の整いやすい行動や条件が呼ばれ、好ましい循環が続きやすくなった状態。

## CCTで大切にすること

- 一つの原因へ決めつけない
- 行動を道徳的に善悪で分類しない
- 中間のつながりを飛ばさない
- 症状だけでなく、その前後を見る
- 大きな改革より、循環を変えやすい一点を探す
- 介入後を観察する
- 仮説が外れれば更新する

## 6つの視点

既存サイトで使う「身体反応・感情/欲求・生活条件・行動・生活リズム・次の状態」は、
人生や原因を六種類に分類する基本要素ではない。

複雑な循環を読みやすくするための**6つの観察視点**であり、
記事の因果連鎖をこの6分類へ強制的に当てはめない。

## 研究との関係

CCT全体が一つの臨床試験で有効性を証明された治療法、という位置づけではない。

記事では、
- 個々の研究で観察・検証されていること
- 複数知見を日常の循環へつないだCCTの解釈
を区別する。

ただし本文を「これは仮説です」の連続にして読みにくくしない。
研究の射程とCCTの読み解きが自然に分かる文章にする。

## 東洋医学など別理論との関係

CCTは現代医学だけに立脚するものでも、東洋医学を根拠とするものでもない。

東洋医学など別の体系には、
長年の人間観察から状態のまとまりを捉えてきた言葉がある。

現代研究と理論体系は異なるが、
「異なる視点から見ても似たまとまりが見える」という比較は、
生活理解を厚くする補助線になりうる。

必要な記事では十分に扱ってよい。
ただし現代医学と同じ機序を証明しているようには書かない。

## CCT Labの記事で目指す読後感

読者が、

「自分は意志が弱い」
ではなく
「こういう一周になっていたのかもしれない」

と見方を変え、

「では、どこを少し変えると次が変わるだろう」

と考えられること。

CCTを覚えてもらうこと自体より、
CCTの見方を一度体験してもらうことを優先する。
